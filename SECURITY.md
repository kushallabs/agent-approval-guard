# Security reporting

Use [GitHub's private reporting form](https://github.com/kushallabs/agent-approval-guard/security/advisories/new) to report a problem in Agent Approval Guard. Include the affected commit or release and a minimal reproduction with fabricated values. Omit live credentials, private source, and logs with personal or sensitive data.

For an exposure in your own repository, revoke the affected credential through its provider and follow your incident response process. For issues in Claude Code itself, use [Anthropic's disclosure program](https://www.anthropic.com/responsible-disclosure-policy).
